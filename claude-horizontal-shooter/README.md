# claude-horizontal-shooter

Claude で作成した横スクロールシューティングゲーム「SONIC RAY」。
依存ライブラリなしの単一 HTML ファイル(Canvas + Vanilla JS)で動作します。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

```
# 例: ローカルサーバーを立てる場合
npx serve .
```

### 操作

| キー | 動作 |
|------|------|
| ←↑→↓ / WASD | 移動 |
| Z / SPACE | ショット(押しっぱなし可) |
| ENTER | 決定・ストーリー送り |
| M | サウンドのミュート切り替え |

### スマホ / タブレット(タッチ操作)
タッチ対応端末ではゲーム画面の下にバーチャルパッドが自動で表示されます。
表示されない場合は「🎮 タッチ操作 ON/OFF」ボタンで手動切り替えできます。

| 操作 | 動作 |
|------|------|
| 左のスティック | 移動(ドラッグで8方向) |
| SHOT ボタン | ショット(押しっぱなし可) |
| START ボタン / 画面タップ | 決定・ストーリー送り |

## 特徴

### ストーリー
機械生命体〈ヴォイド〉に制圧されたコロニー〈アヴァロン〉を奪還するため、
パイロットのリオが試作戦闘機「ソニックレイ」で単機出撃する。
オープニング・ステージ間・エンディングでストーリーが展開します。

### ステージごとに特長ある地形(全5ステージ)

| ステージ | 地形の特長 | ボス |
|---------|-----------|------|
| STAGE 1 草原地帯 | なだらかな丘と山。地上砲台 | 装甲飛行艇 アイアンロック |
| STAGE 2 地底洞窟 | 天井と床が迫る洞窟。狭い通路、落下する鍾乳石 | 洞窟の主 深淵の眼 |
| STAGE 3 氷結峡谷 | 上下から交互に突き出す鋭い氷柱。降雪 | 氷竜 アイスヴァーン(蛇行する長体) |
| STAGE 4 嵐の空域 | 低い雲海と開けた空。稲妻、乱気流が機体を揺らす | 嵐の暴君 テンペスト |
| STAGE 5 機械要塞 | 段差状のブロック地形と隔壁。可動式クラッシャー | コア・シタデル(コア開閉ギミック) |

**ボス戦では地形がせり出して消え、開けたアリーナで戦えます。**

### 地形を活かした敵配置
ステージ生成時に地形を解析して敵を配置します。

- 草原: 丘や山の頂上に砲台
- 洞窟: 狭い通路の入口を守る上下砲台と、通路手前の鍾乳石の罠
- 氷結峡谷: 床の氷柱の先端に砲台、天井の氷柱の真下は落下トラップ
- 嵐の空域: 雲海に潜み、接近すると浮上して撃ってくる伏兵
- 機械要塞: 隔壁の狭間にクラッシャー、前後の床・天井に砲台

### アーケード風ピクセルグラフィック
ワールドを 320×180 の低解像度キャンバスに描画してから拡大転送する方式で、
ドット絵風の見た目を実現しています(UI は高解像度で描画)。

- 多層パララックス背景: 太陽と二重の山並み(草原)、岩柱と輝く結晶(洞窟)、
  オーロラと氷峰(峡谷)、雨と稲妻(嵐)、窓明かりの構造物と配管(要塞)
- 陰影付き地形: 暗い深部+明るい表層バンド+エッジライン。草むら・花・
  紫水晶・氷のきらめき・パネル継ぎ目・警告灯などステージ別の装飾
- 多色ドット絵スプライト: シェーディング付き自機(3段階エンジン炎・
  マズルフラッシュ)、輪郭+ハイライト付きの敵、点滅ビーコンの運搬機
- エフェクト: 発光する自機ボルト、脈動する敵弾、衝撃波リング+
  白→黄→橙と色が変わる爆発破片、ボスの発光・放電・回転レーダー
- CRT 風の走査線

### パワーアップ
オレンジ色の敵(編隊の最後尾・アイテム運搬機)を倒すとアイテムが出現します。
運搬機は道中に定期的に飛来します。

| アイテム | 効果 |
|---------|------|
| P | ショット強化(単発 → 2連装 → 3方向 → +後方 → 5方向 → +上下・連射速度UP の6段階) |
| S | スピードアップ(最大4段階) |
| M | ミサイル(Lv1: 斜め下 / Lv2: 上下同時発射) |
| B | バリア(最大4発分のダメージを防ぐ) |
| O | オプション(自機の軌跡を追尾する子機。最大2機、自機と同じ弾をまとめて発射) |
| U | 1UP(残機+1、最大6) |

被弾するとパワーアップはリセットされます。ハイスコアは localStorage に保存されます。

### サウンド
WebAudio によるレトロ風効果音(ショット・爆発・アイテム・警報など)。
右下の 🔊 ボタンまたは M キーでミュートできます。

## 動作確認

Playwright(Chromium)で全5ステージの道中描画 → ボス出現 → アリーナ化 →
撃破 → ステージ遷移 → エンディングまでの自動テストを実施し、
JS エラーがないことを確認済みです。
タッチ操作は iPhone / Pixel エミュレーションでパッド表示・移動・連射・
メニュー送りを確認しています。
