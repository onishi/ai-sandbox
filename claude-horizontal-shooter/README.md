# claude-horizontal-shooter

Claude で作成した横スクロールシューティングゲーム「SONIC RAY」。
依存ライブラリなしの単一 HTML ファイル(Canvas + Vanilla JS)で動作します。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

```
# 例: ローカルサーバーを立てる場合
npx serve .
```

### 操作

| キー | 動作 |
|------|------|
| ←↑→↓ / WASD | 移動 |
| Z / SPACE | ショット(押しっぱなし可) |
| ENTER | 決定・ストーリー送り |

### スマホ / タブレット(タッチ操作)
タッチ対応端末ではバーチャルパッドが自動で表示されます。

| 操作 | 動作 |
|------|------|
| 左下のスティック | 移動(ドラッグで8方向) |
| 右下の SHOT ボタン | ショット(押しっぱなし可) |
| START ボタン / 画面タップ | 決定・ストーリー送り |

## 特徴

### ストーリー
機械生命体〈ヴォイド〉に制圧されたコロニー〈アヴァロン〉を奪還するため、
パイロットのリオが試作戦闘機「ソニックレイ」で単機出撃する。
オープニング・ステージ間・エンディングでストーリーが展開します。

### ステージごとに特長ある地形(全3ステージ)

| ステージ | 地形の特長 |
|---------|-----------|
| STAGE 1 草原地帯 | なだらかな丘と山。開けた空、地上砲台 |
| STAGE 2 地底洞窟 | 天井と床が迫る洞窟。狭い通路、落下する鍾乳石 |
| STAGE 3 機械要塞 | 段差状のブロック地形と隔壁。可動式クラッシャー |

各ステージの最後にはボスが待ち構えています(STAGE 3 のボスはコアの開閉ギミックあり)。

### パワーアップ
オレンジ色の敵(編隊の最後尾)を倒すとアイテムが出現します。

| アイテム | 効果 |
|---------|------|
| P | ショット強化(単発 → 2連装 → 3方向) |
| S | スピードアップ(最大4段階) |
| M | ミサイル装備(斜め下に発射) |
| B | バリア(3発分のダメージを防ぐ) |

被弾するとパワーアップはリセットされます。ハイスコアは localStorage に保存されます。

## 動作確認

Playwright(Chromium)でタイトル → ストーリー → 各ステージ描画 → ボス出現まで
スモークテストを実施し、JS エラーがないことを確認済みです。
タッチ操作は iPhone エミュレーション(landscape)でパッド表示・移動・連射・
メニュー送りを確認しています。
